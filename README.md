# Waiting Entertainment Prototype

## Overview

Waiting Entertainment is a browser-based multiplayer party game platform designed for restaurant waiting scenarios.

First prototype game:

## 餐桌推推王 (Table Push King)

A 60-second physics party game:

- 2-8 players
- Large screen host experience
- Mobile phone as controller
- Simple controls
- Physics-based pushing and falling
- AI bots when players are insufficient

## Project Goal

Validate the core experience:

> Can strangers in a restaurant understand and enjoy a multiplayer physical game within seconds?

## Technology Direction

- Three.js
- Rapier3D
- TypeScript
- Node.js
- Socket.IO / Colyseus compatible architecture

## Development Principle

This is not a traditional mobile game.

It is a public entertainment device:

- Big screen first
- Instant join
- Short sessions
- High spectator value

## Development Phases

- Phase 0: Product and architecture design
- Phase 1: Engine foundation
- Phase 2: Physics prototype
- Phase 3: Multiplayer synchronization
- Phase 4: Mobile controller
- Phase 5: AI bots
- Phase 6: Experience optimization
